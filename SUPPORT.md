# Support

WhisprLink is an early-stage open-source project.

- **Bug reports:** use the Bug report issue form with reproducible steps.
- **Feature proposals:** use the Feature request form and explain the user problem.
- **Product/architecture discussion:** open a focused Issue.
- **Security vulnerabilities:** do not use public Issues; follow SECURITY.md.

Before asking for help, check README.md, docs/PRODUCT_SPEC.md, and docs/DEVELOPMENT.md.

Never post Telegram bot tokens, database credentials, private message content, or other personal data.
