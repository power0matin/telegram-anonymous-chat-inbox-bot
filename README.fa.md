> **وضعیت: Pre-alpha** — اسکلت اجرایی اولیه با Python و aiogram اضافه شده است: تنظیمات اعتبارسنجی‌شده، اجرای Polling، پاسخ پایه به دستور /start، تست‌های واحد و CI. قابلیت‌های اصلی هنوز پیاده‌سازی نشده‌اند.

## قابلیت‌های برنامه‌ریزی‌شده

- **چت تصادفی ناشناس:** اتصال دو کاربر برای گفت‌وگوی خصوصی، بدون نمایش هویت تلگرامی یکدیگر.
- **صندوق پیام ناشناس:** لینک اختصاصی برای دریافت متن و رسانه، بدون نمایش هویت فرستنده.
- **پاسخ زنجیره‌ای:** بازکردن پیام و ادامه مکالمه در یک رشته زمانی.

## روند صندوق پیام

1. کاربر ربات را Start می‌کند و لینک اختصاصی صندوق خود را فعال می‌کند.
2. شخص دیگری لینک را باز کرده و متن یا رسانه پشتیبانی‌شده می‌فرستد.
3. صاحب صندوق فقط اعلان دریافت پیام می‌کند؛ محتوا در اعلان نمایش داده نمی‌شود.
4. صاحب صندوق دکمه **مشاهده پیام** را می‌زند و محتوا پس از درخواست صریح او ارسال می‌شود.
5. پس از تحویل موفق محتوا، رویداد بازشدن ثبت می‌شود و فرستنده اعلان دریافت می‌کند.
6. هر دو طرف می‌توانند در همان رشته پیام بدهند؛ بلاک، گزارش و بستن مکالمه نیز در نظر گرفته شده است.

«دیده‌شدن» یعنی بازکردن عمدی پیام داخل WhisprLink؛ این قابلیت رسید خواندن بومی تلگرام نیست.

## فناوری‌های هدف

Python و aiogram 3، معماری Modular Monolith، PostgreSQL، SQLAlchemy 2، Alembic، Redis، Pydantic Settings، pytest، Ruff و Docker Compose.

PostgreSQL منبع اصلی وضعیت کاربران و مکالمات خواهد بود. Redis برای هماهنگی موقت و Rate Limit استفاده می‌شود و نباید تنها محل نگهداری وضعیت مکالمه باشد.

## راه‌اندازی اسکلت فعلی

به Python 3.12 یا جدیدتر و یک توکن آزمایشی تلگرام نیاز داری.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

مقدار TELEGRAM_BOT_TOKEN را داخل فایل محلی .env قرار بده و اجرا کن:

```powershell
python -m whisprlink
```

در این مرحله فقط دستور /start پاسخ می‌دهد؛ صندوق پیام و چت تصادفی هنوز وجود ندارند.

## وضعیت توسعه

کد فعلی فقط بارگذاری تنظیمات، راه‌اندازی بات و پاسخ به /start را پوشش می‌دهد. Schema دیتابیس، Migrationها، Redis، صندوق پیام، پاسخ‌ها، موتور تطبیق تصادفی، مدیریت گزارش‌ها، پشتیبانی رسانه و استقرار Production هنوز پیاده‌سازی نشده‌اند. توکن واقعی یا اطلاعات کاربران را در Git قرار ندهید.

## حریم خصوصی

«ناشناس» به معنی پنهان بودن هویت دو طرف از یکدیگر در تجربه ربات است. گرداننده ربات و تلگرام همچنان اطلاعات لازم برای ارسال پیام را پردازش می‌کنند. پروژه ادعای رمزنگاری سرتاسری ندارد.
