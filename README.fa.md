> **وضعیت: Pre-alpha** — این مخزن فعلاً شامل مستندات محصول و معماری است. کد اجرایی ربات و نسخه قابل استقرار هنوز پیاده‌سازی نشده‌اند.

## قابلیت‌ها

- **چت تصادفی ناشناس:** اتصال دو کاربر برای گفت‌وگوی خصوصی، بدون نمایش هویت تلگرامی یکدیگر.
- **صندوق پیام ناشناس:** لینک اختصاصی برای دریافت متن و رسانه، بدون نمایش هویت فرستنده.
- **پاسخ زنجیره‌ای:** بازکردن پیام و ادامه مکالمه در یک رشته زمانی.

## روند صندوق پیام

1. کاربر ربات را Start می‌کند و لینک اختصاصی صندوق خود را فعال می‌کند.
2. شخص دیگری لینک را باز کرده و متن یا رسانه پشتیبانی‌شده می‌فرستد.
3. صاحب صندوق فقط اعلان دریافت پیام می‌کند؛ محتوا در اعلان نمایش داده نمی‌شود.
4. صاحب صندوق دکمه **مشاهده پیام** را می‌زند و محتوا پس از درخواست صریح او ارسال می‌شود.
5. پس از تحویل موفق محتوا، رویداد بازشدن ثبت می‌شود و فرستنده اعلان دریافت می‌کند.
6. هر دو طرف می‌توانند در همان رشته پیام بدهند؛ بلاک، گزارش و بستن مکالمه نیز در نظر گرفته شده است.

«دیده‌شدن» یعنی بازکردن عمدی پیام داخل WhisprLink؛ این قابلیت رسید خواندن بومی تلگرام نیست.

## فناوری‌های هدف

Python و aiogram 3، معماری Modular Monolith، PostgreSQL، SQLAlchemy 2، Alembic، Redis، Pydantic Settings، pytest، Ruff و Docker Compose.

PostgreSQL منبع اصلی وضعیت کاربران و مکالمات است. Redis برای هماهنگی موقت و Rate Limit استفاده می‌شود و نباید تنها محل نگهداری وضعیت مکالمه باشد.

## وضعیت توسعه

Schema دیتابیس، Handlerها، صندوق پیام، موتور تطبیق، تست‌ها و Docker هنوز پیاده‌سازی نشده‌اند. در حال حاضر ربات عملیاتی برای استقرار وجود ندارد. توکن واقعی تلگرام یا اطلاعات کاربران را در مخزن قرار ندهید.

## حریم خصوصی

«ناشناس» به معنی پنهان بودن هویت دو طرف از یکدیگر در تجربه ربات است. گرداننده ربات و تلگرام همچنان اطلاعات لازم برای ارسال پیام را پردازش می‌کنند. پروژه ادعای رمزنگاری سرتاسری ندارد.
